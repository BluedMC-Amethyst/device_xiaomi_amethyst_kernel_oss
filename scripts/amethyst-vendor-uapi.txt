# Vendor UAPI headers exported by headers_install, which LineageOS turns into
# the qti_*_kernel_headers libraries that qcom-caf HALs build against.
# Xiaomi's Bazel uapi dist provided them on stock; this kernel does not carry
# them. Each <source> (relative to the LineageOS tree) is committed as
# include/uapi/<dest>; amethyst-los-setup.sh warns when a source has changed.
#
# Prefer the module source that is actually built, so userspace and the
# driver agree on the ABI. Legacy CAF headers that no built module carries
# come from the stock header dump (device/xiaomi/amethyst-kernel).
#
# The securemsm module splits qseecom.h: its ioctls are in qseecom_api.h.
# linux/msm_audio.h is the legacy CAF header, not audio/linux/msm_audio.h.
#
# <dest>	<source>
